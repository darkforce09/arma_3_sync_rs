# Icons

The 42 SVG icons and `app-rendered.png` are copied unmodified from the Java Arma3Sync project
(GPL-3.0, Java commit `b7753ce`, `src/main/resources/resources/icons/`).

- The single-path 24×24 glyphs appear to derive from Google Material Symbols (Apache-2.0, which
  is GPL-3.0 compatible). For example, `check.svg` matches Material Symbols "check". This is an
  inference from the path data and the Iconify export format; it is not documented upstream.
- `app.svg` and `app-rendered.png` are the ArmA3Sync logo (project branding).
- `community.svg` is the "PzBrig21" community crest (community branding).
